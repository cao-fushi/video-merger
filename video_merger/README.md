# 视频批量合成工具

一个功能强大的视频批量合成程序，支持指定开头视频、多种合成策略和批量处理。

## 功能特点

### 核心功能
- **批量导入视频**：支持单个文件、文件夹批量导入，兼容江湖工具箱JSON格式
- **指定开头视频**：可手动指定每个合成视频的第一个片段
- **多种合成策略**：
  - 按顺序轮流开头
  - 指定固定开头视频
  - 随机选择开头
- **灵活的合成配置**：
  - 自定义每组片段数（2个、3个或更多）
  - 设置合成数量（全部组合或自定义数量）
  - 自定义文件前缀命名

### 预处理选项（可选）
- 统一分辨率
- 统一帧率
- 编码器选择（H.264/H.265）
- 质量设置（高/中/低）

### 输出管理
- 按开头视频自动分组到子目录
- 自定义前缀 + 序号命名
- 实时进度显示

## 系统要求

- **Python**: 3.10 或更高版本
- **FFmpeg**: 需要安装并添加到系统PATH
- **依赖库**: PyQt5, ffmpeg-python

## 安装步骤

### 1. 安装Python依赖

```bash
pip install PyQt5 ffmpeg-python
```

### 2. 安装FFmpeg

**Windows:**
1. 访问 https://ffmpeg.org/download.html
2. 下载Windows版本
3. 解压到目录，例如 `C:\ffmpeg`
4. 将 `C:\ffmpeg\bin` 添加到系统PATH环境变量

**或者使用scoop:**
```bash
scoop install ffmpeg
```

**或者使用chocolatey:**
```bash
choco install ffmpeg
```

### 3. 验证安装

```bash
python --version
ffmpeg -version
```

## 使用方法

### 启动程序

```bash
cd d:\123\ai\zlsc
python -m video_merger.main
```

或者双击 `start_video_merger.bat`

### 基本使用流程

1. **添加视频**
   - 点击"添加视频文件"选择单个或多个视频
   - 或点击"添加文件夹"批量导入
   - 或点击"从JSON加载"导入江湖工具箱格式的数据

2. **设置开头视频**
   - 在视频列表中点击某行的"设为开头"按钮
   - 或在右侧设置面板中选择开头模式：
     - "不指定"：按顺序轮流作为开头
     - "指定开头视频"：从下拉框选择
     - "随机选择开头"：随机选择

3. **配置合成参数**
   - 设置每组片段数（默认2个）
   - 选择合成数量模式
   - 设置文件前缀和输出目录

4. **开始合成**
   - 点击"预览合成方案"查看将要生成的组合
   - 点击"开始合成"开始批量处理
   - 等待完成

## 常见问题

### Q: 提示"未检测到FFmpeg"
A: 请确保FFmpeg已正确安装并添加到系统PATH。可以在命令行运行 `ffmpeg -version` 验证。

### Q: 合成后的视频画质不好
A: 在预处理设置中将"质量"调整为"高"，但会增加处理时间和文件大小。

### Q: 如何快速选择多个视频设为开头？
A: 可以在视频列表中右键点击，选择"设为开头视频"。

### Q: 支持哪些视频格式？
A: 支持 MP4, AVI, MKV, MOV, WMV, FLV, WebM, M4V 等常见格式。
